## Project Overview
**webgpu_streetview** renders Google Maps Street View imagery using WebGPU for high-performance, custom visual processing.

- **Core Idea**: Take familiar Street View data and give it a modern WebGPU twist (effects, stylization, real-time manipulation).
- **Potential**: Artistic reinterpretation of real-world locations, creative filters, or interactive experiences.

## Technology Stack
- TypeScript + Vite
- WebGPU (WGSL)
- Google Maps Street View API integration

## Grok Guidelines
- **Performance with Real Data**: Handling large Street View tiles efficiently is key.
- **Creative Effects**: The value comes from what you *do* to the imagery — stylization, abstraction, time-of-day simulation, weather overlays, etc.
- **Interactivity**: Allow users to navigate locations while applying real-time effects.
- **API Integration**: Be mindful of Google Maps API limits and best practices.

## Common Tasks
- Add new post-processing effects and filters
- Improve tile loading and streaming performance
- Create artistic “looks” or themes
- Add UI for location search and effect controls
- Optimize for smooth panning and zooming
